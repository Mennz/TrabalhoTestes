1. Visão geral

1.1 Objetivo

O documento do plano de testes tem como objetivo relatar os requisitos que serão testados e descrever as técnicas adotadas nesses testes: 10 testes unitários automatizados (xUnit), 10 testes funcionais automatizados (Selenium WebDriver) e 10 testes funcionais manuais com registro de prints, além da refatoração de 2 métodos e do relatório de defeitos.

Carga horária estimada: 12 horas (planejamento 2 h; testes unitários 2 h; testes Selenium 3 h; testes manuais 2 h; refatoração e reteste 1 h; relatório e vídeo 2 h).

Recursos necessários: computador com Windows 10, .NET SDK 8, Google Chrome, xUnit 2.9, Selenium WebDriver 4.27 (o ChromeDriver é baixado automaticamente pelo Selenium Manager), Git e GitHub, Visual Studio ou Visual Studio Code.

1.2 Descrição do produto a ser testado

O Sistema de Gerenciamento de Personagens de RPG é uma aplicação de console em C# (.NET 8), desenvolvida como Trabalho Interdisciplinar de Programação Orientada a Objetos. Ele permite criar personagens de quatro classes (Guerreiro, Mago, Druida e Bardo) por meio do padrão Factory Method, controlar nível, experiência, atributos e habilidades, e gerenciar um inventário com armas, equipamentos, consumíveis e munição (adicionar, remover, buscar, ordenar, equipar e desequipar). Os personagens podem ser salvos e carregados em JSON.

GitHub do sistema (TI): https://github.com/ThiagoBotelho12/TrabalhoPOO2
GitHub dos testes: https://github.com/Mennz/TrabalhoTestes

Como o sistema é de console e o Selenium só testa páginas web, o projeto de testes inclui uma tela web mínima (projeto Sistema.Web) que chama as mesmas classes do sistema (GerenciadorPersonagens, fábricas, Inventario, Personagem), sem reescrever nenhuma regra de negócio.

2. Escopo

2.1 Planejamento do escopo

Os testes ocorrerão nos módulos de criação de personagens, gerenciamento do personagem (experiência, nível, habilidades e características) e inventário (itens, busca, ordenação e equipamentos). Serão empregados testes de unidade (classes Item, ItemConsumivel, ItemMunicao, Inventario, Personagem e fábricas) e testes de sistema (funcionais automatizados e manuais). A persistência em JSON (opções 6 e 7) e os métodos de combate (Atacar e UsarHabilidadeEspecial) não serão testados neste plano.

3. Itens-alvo dos testes

UC1: Criar personagem

01 - Descrição da história/necessidade: Como jogador, quero criar um personagem informando nome, raça, alinhamento, nível e classe, e depois altura, peso, cores de cabelo e olhos, data de nascimento e história.

02 - O que deve ser feito: Menu "Criar novo personagem" com a leitura dos dados; criação pela fábrica da classe escolhida; itens iniciais da classe; seleção automática do personagem criado.

03 - Regras de negócio: Nome com pelo menos 2 caracteres; raça e alinhamento obrigatórios; nível entre 1 e 100; classe entre 1 e 4.

UC2: Gerenciar personagem

01 - Descrição: Como jogador, quero ver o status, ganhar experiência, subir de nível, aprender habilidades e editar as características do meu personagem.

02 - O que deve ser feito: Exibir status, equipamentos e habilidades; adicionar experiência; editar características; rolar atributos.

03 - Regras de negócio: XP deve ser positivo; o limite do nível N é 100 × 1,5^(N-1); ao subir de nível os atributos aumentam e vida e mana são restauradas; habilidades exigem nível mínimo.

UC3: Gerenciar inventário

01 - Descrição: Como jogador, quero guardar, remover, buscar e ordenar os itens do meu personagem.

02 - O que deve ser feito: Adicionar armas, equipamentos, consumíveis e munição; remover por nome; buscar por nome, tipo ou raridade; ordenar por nome, peso ou valor.

03 - Regras de negócio: Item com nome, peso maior que zero e valor não negativo; o peso total não pode passar da capacidade (50 + nível × 10 kg); munição tem peso e valor proporcionais à quantidade.

UC4: Equipar e desequipar

01 - Descrição: Como jogador, quero equipar armas e armaduras nos slots do personagem e tirá-las depois.

02 - O que deve ser feito: Listar os itens equipáveis; equipar no slot do item; desequipar devolvendo ao inventário.

03 - Regras de negócio: Slots Cabeça, Torso, Mãos, Pés e Arma; requisito de atributo mínimo 10; cada ponto de defesa soma 5 de vida máxima.

Menu.CriarPersonagemMétodo longo (≈ 75 linhas) que lê dados, escolhe a classe, cria o personagem e configura as características num bloco só.     : base(nome, pesoUnitario * quantidade, valorUnitario * quantidade, "Munição", raridade)

public bool Usar(int quantidade = 1)
{
    if (Quantidade >= quantidade)
    {
        Quantidade -= quantidade;
        Peso -= (Peso / (Quantidade + quantidade)) * quantidade;
        Valor -= (Valor / (Quantidade + quantidade)) * quantidade;
        return true;
    }
    return false;
}

                  int quantidade, string tipo, string raridade = "Comum")
    : base(nome, pesoUnitario * quantidade, valorUnitario * quantidade, "Munição", raridade)
{
    PesoUnitario = pesoUnitario;
    ValorUnitario = valorUnitario;
    Quantidade = quantidade;
    Tipo = tipo;
}

public bool Usar(int quantidade = 1)
{
    if (!QuantidadeValida(quantidade))
        return false;

    Quantidade -= quantidade;
    RecalcularPesoEValor();
    return true;
}

private bool QuantidadeValida(int quantidade) => quantidade > 0 && quantidade <= Quantidade;

private void RecalcularPesoEValor()
{
    Peso = PesoUnitario * Quantidade;
    Valor = ValorUnitario * Quantidade;
}
